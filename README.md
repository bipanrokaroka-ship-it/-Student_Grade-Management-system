2. Project Purpose
The Student Grade Management System is a simple program developed using C programming.
The main purpose of this project is to manage student information and academic scores easily. It allows users to add students, view student records, calculate total and average scores, search for students, and update scores.
This project demonstrates the practical use of basic programming concepts learned during the semester.
3. Main Features
The program includes the following features:
1. Add Student: Register a new student using student ID, name, and score.
2. Print All Students: Display all registered students and their grades.
3. Calculate Total and Average: Calculate the total score and average score.
4. Search Student by ID: Find a student's information using their ID.
5. Update Score: Change an existing student's score using their ID.
6. Exit: Close the program safely.
